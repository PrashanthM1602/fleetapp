## 📌 Overview

The **Fleet Management System** is designed to streamline and optimize fleet operations through a centralized platform.  
It enables efficient management of vehicles, driver activities, inspections, and operational analytics.

✔ Built with scalability and real-world usability in mind  
✔ Clean UI/UX for better user experience  
✔ API-driven architecture for flexibility  

---

## ✨ Key Features

- 🚘 **Vehicle Management** – Add, update, and manage fleet vehicles  
- 👨‍✈️ **Driver Tracking** – Monitor driver status and activity  
- 📋 **Inspection System** – Manage inspection requests and records  
- 🔐 **Secure Authentication** – JWT-based login system  
- 📊 **Analytics Dashboard** – Insights for better decision-making  
- 🔄 **REST API Integration** – Smooth backend communication  
- 📱 **Responsive Design** – Works across all devices
